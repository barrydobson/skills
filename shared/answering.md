# Putting choices to the user

Use this format whenever a skill asks the user to decide something.

- Number each question. Give it lettered options, with your recommended option first and marked `(recommended)`.
- Expect shorthand answers: `1a 2c`, `1`, `option a`, `all except 3`, `agree`, `go`. `go`, `agree` and `yes` accept every recommendation. `all except 3` accepts every recommendation but question 3; ask again about that one only.
- Once the user has answered, act on the answers. Do not ask them to confirm again.
